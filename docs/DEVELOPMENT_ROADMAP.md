# Development Roadmap

| Milestone | เนื้อหา | สถานะ |
|---|---|---|
| M1 Foundation | monorepo, Prisma schema+migration+seed, auth, RBAC, audit, layout, dashboard, เรือ, พนักงาน+เอกสาร, เที่ยวเรือ, สัตว์น้ำ, แจ้งเตือน, PWA/offline catch, Docker, docs | ✅ |
| M2 Fleet ops | GPS: adapter HTTP (generic JSON, OsmAnd/Traccar Client, AIS push) + device key, ส่งตำแหน่งจากมือถือ (PWA), แผนที่ Leaflet+OSM, เส้นทางย้อนหลัง, ขาดสัญญาณ, geofence, โหมดสาธิตติดป้าย; น้ำมัน: ถังบริษัท ledger (ต้นทุนเฉลี่ยเคลื่อนที่), รับ/จ่ายเข้าเที่ยว/ปรับยอด, ชั่วโมงเครื่อง, รายงาน ลิตร/กก. · บาท/กก. · ลิตร/ชม. | ✅ |
| M2.1 | MQTT bridge (ใช้ ingest service เดิม), ดึงข้อมูลจากผู้ให้บริการ AIS/VMS (ต้องมี credential), เลือกพื้นที่ geofence บนแผนที่ | ⏳ |
| M3 Supply chain | ผู้ขาย, PR→PO→GR (แยกผู้สร้าง/ผู้อนุมัติ, รับบางส่วน, ปิด/ยกเลิก), คลัง (ledger append-only, ต้นทุนเฉลี่ยเคลื่อนที่, ห้ามติดลบเว้นอนุมัติ, โอน, ตรวจนับ, จุดสั่งซื้อ+แจ้งเตือน, มูลค่า), เบิกเข้าเรือ→ต้นทุนเที่ยว, ซื้อส่งตรงเข้าเที่ยว | ✅ |
| M3.1 | รับคืนสินค้าให้ผู้ขาย, lot/วันหมดอายุของวัสดุ | ⏳ |
| M4 Sales | ลูกค้า, ล็อต (เที่ยว×ชนิด×เกรด, กันขายเกิน), ใบสั่งขาย→ใบแจ้งหนี้, รับชำระ/ยกเลิกใบเสร็จ, ใบลดหนี้, ลูกหนี้ aging, รายงานยอดขาย, รายได้/กำไรขั้นต้นในสรุปเที่ยว, KPI แดชบอร์ด | ✅ |
| M5 Maintenance | แผนบำรุงรักษา (ตามวัน/ชั่วโมงเครื่อง), ใบสั่งซ่อม (หยุดเรือระหว่างซ่อม, อะไหล่จากคลัง, ค่าแรง/ค่าจ้างภายนอก, แนบไฟล์), log ชั่วโมงเครื่อง (ห้ามถอยหลังเว้นรีเซ็ต, รับจากเที่ยวเรือ), แจ้งเตือนครบรอบ, รายงานค่าซ่อม | ✅ |
| M6 Payroll | กฎค่าตอบแทนตั้งค่าได้ (รายเดือนเฉลี่ยตามวัน/รายวันในทะเล/เหมาเที่ยว/ส่วนแบ่ง %/ตามน้ำหนัก; ลำดับ พนักงาน>เรือ>ตำแหน่ง>ทั่วไป), เบิกล่วงหน้า/เงินกู้ผ่อน (หักไม่ให้สุทธิติดลบ, ตัดยอดตอนอนุมัติ), รายการปรับปรุง, งวด DRAFT→CALCULATED→APPROVED→PAID (ผู้คำนวณ≠ผู้อนุมัติ, กันพนักงานซ้ำงวด), สลิปพิมพ์ได้พร้อมสูตรทุกบรรทัด, ไฟล์โอน CSV, ค่าแรงลูกเรือในสรุปเที่ยว/แดชบอร์ด | ✅ |
| M6.1 | ประกันสังคม/ภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1), รูปแบบไฟล์โอนเฉพาะธนาคาร, สลิป PDF ส่งอีเมล, OT/วันหยุด | ⏳ |
| M7 Accounting | ผังบัญชีมาตรฐาน (แก้ไขได้), สมุดรายวันคู่ (ร่าง→ผ่านรายการโดยคนละคน→กลับรายการ; ผ่านแล้วแก้/ลบไม่ได้ด้วย DB trigger), งวดบัญชีรายเดือน (ตรวจก่อนปิด, เปิดใหม่ต้องมีเหตุผล), ลงบัญชีอัตโนมัติจาก 12 ประเภทเอกสาร (idempotent, ยกเลิกเอกสาร = กลับรายการ), มิติเรือ/เที่ยว, งบทดลอง/กำไรขาดทุน (รายเรือ)/งบแสดงฐานะการเงิน/บัญชีแยกประเภท + CSV/พิมพ์ | ✅ |
| M7.1 | ใบแจ้งหนี้ผู้ขาย (จับคู่ใบรับสินค้า/ล้างค่าใช้จ่ายค้างจ่าย, กันใบกำกับซ้ำ, ผู้อนุมัติ≠ผู้บันทึก), จ่ายชำระหลายใบ + หัก ณ ที่จ่าย, อายุเจ้าหนี้, บัญชีธนาคาร + กระทบยอด (ติ๊กรายการ, ผลต่างต้องเป็น 0, รายการละครั้ง), รายงานภาษีขาย/ซื้อ (ฐาน ภ.พ.30) และ ภ.ง.ด.3/53 | ✅ |
| M7.2 | งบกระแสเงินสด, ปิดบัญชีสิ้นปี, ทะเบียนทรัพย์สิน/ค่าเสื่อม, ภ.ง.ด.1 (เงินเดือน), ไฟล์ยื่นภาษีอิเล็กทรอนิกส์, งบประมาณ | ⏳ |
| M8 Reports & hardening | รายงาน PDF/Excel/CSV ทุกโมดูล, 2FA, เข้ารหัสคอลัมน์, E2E Playwright CI, load test, pen-test | ⏳ |

แต่ละ milestone: typecheck → lint → unit/integration/API tests → build → อัปเดต docs
