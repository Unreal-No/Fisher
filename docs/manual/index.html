    เครื่องที่ติดตั้ง localhost:8080 เครื่องอื่นในออฟฟิศใช้ IP ของเครื่องนั้น

  4. เปิด 2FA (แนะนำ)

    บัญชีของฉัน → ยืนยันตัวตนสองขั้นตอน ใช้แอป Authenticator บนมือถือ

บันทึกสัตว์น้ำ

เมนู สัตว์น้ำที่จับได้ · บันทึกน้ำหนักที่จับได้จากเที่ยวเรือ (ยังไม่ใช่น้ำหนักขาย) ทุกการแก้ไขมีประวัติ

  1. กด “บันทึกสัตว์น้ำ”

    บนมือถือหรือคอมพิวเตอร์ก็ได้

  2. กรอกรายละเอียด

    เที่ยวเรือ ชนิด เกรด น้ำหนัก (กก.) จำนวนเข่ง วิธีเก็บรักษา

  3. บันทึก

    น้ำหนักรวมขึ้นในหน้าเที่ยวเรือและแดชบอร์ดทันที

กลางทะเลไม่มีสัญญาณ? บันทึกได้ตามปกติ รายการจะรออยู่ในแท็บ รอซิงก์ (ออฟไลน์) และส่งเข้าระบบเองเมื่อมือถือกลับมาออนไลน์

แท็บ

รายการ ทุกครั้งที่บันทึก · สรุป รวมตามชนิด/เรือ · รอซิงก์ รายการที่ยังไม่ส่ง

บันทึกได้ตั้งแต่ออกเรือจนถึงรอสรุปเที่ยว เพิ่มชนิดสัตว์น้ำได้ที่เมนู ชนิดสัตว์น้ำ

ติดตามเรือ GPS

เมนู ติดตามเรือ (GPS) · ดูตำแหน่งสด ย้อนดูเส้นทาง และรู้ว่าเรือพักที่ไหนนานเท่าไร

แผนที่ (สด)

ป้าย สด แปลว่าเชื่อมต่ออยู่ ตำแหน่งขยับเองเมื่อมีข้อมูลเข้า เลือกเรือเพื่อดูเส้นทาง 12 ชั่วโมงล่าสุด

ประวัติการเดินทาง

เลือกเรือ + ช่วงเวลา (เที่ยวปัจจุบัน 24 ชม. 7 วัน 30 วัน กำหนดเอง) ได้เส้นทาง สรุป และไทม์ไลน์ ส่งออก Excel ได้

เขตพื้นที่ (Geofence)

กำหนดวงกลมหรือรูปหลายเหลี่ยม เช่น ท่าเรือ เขตห้ามทำประมง ระบบเตือนเมื่อเรือเข้า-ออก

อ่านประวัติการเดินทางอย่างไร

  • ●จุดเริ่ม (ท่าที่ออก)
  • 1จุดพัก มีหมายเลขตามลำดับ
  • ●ตำแหน่งล่าสุด หรือท่าที่เข้า
  • –เส้นประ = ข้อมูลจำลอง เส้นทึบ = ข้อมูลจริง

น้ำมันและคลังสินค้า

เมนู น้ำมันเชื้อเพลิง และ คลังสินค้า · ของทุกชิ้นที่เข้า-ออกมีรายการกำกับ ยอดคงเหลือคำนวณจากรายการเหล่านี้

  1. ซื้อเข้าถังบริษัท

    บันทึกน้ำมันเข้าถังที่แท็บ ถังน้ำมันบริษัท

  2. เติมเข้าเรือ

    ผูกกับเที่ยวเรือ ยอดในถังลดลงอัตโนมัติ

  3. วัดน้ำมันเหลือตอนเข้าท่า

    ระบบหาน้ำมันที่ใช้จริงของเที่ยว

  4. ดูรายงาน

    ลิตรที่ใช้ บาท/กก. ลิตร/ชม.เครื่อง

คลังสินค้า: 4 แท็บ

  • สต็อกคงเหลือ จำนวนและมูลค่า (ต้นทุนเฉลี่ย)
  • สินค้า รายการวัสดุ อะไหล่ เสบียง
  • ความเคลื่อนไหว ทุกการรับ-จ่าย
  • คลังสินค้า ที่เก็บแต่ละแห่ง

จัดซื้อ

เมนู จัดซื้อ · ขอซื้อ → สั่งซื้อ → รับของ → ตั้งหนี้ → จ่ายเงิน แต่ละขั้นมีผู้อนุมัติ

  1. ใบขอซื้อ

    ร่าง → รออนุมัติ → อนุมัติแล้ว

  2. ใบสั่งซื้อ

    สร้างจากใบขอซื้อ ส่งให้ผู้ขาย

  3. รับสินค้า

    รับบางส่วน หรือรับครบ สต็อกเพิ่มทันที

  4. ใบแจ้งหนี้ผู้ขาย

    บัญชี → เจ้าหนี้ ตั้งหนี้ตามใบสั่งซื้อ

  5. จ่ายชำระ

    หักภาษี ณ ที่จ่ายได้ ลงบัญชีให้เอง

ซ่อมบำรุง

เมนู ซ่อมบำรุง · วางแผนบำรุงรักษาล่วงหน้า และเก็บประวัติค่าซ่อมแยกรายเรือ

  1. แผนบำรุงรักษา

    ทุกกี่วัน หรือทุกกี่ชั่วโมงเครื่อง

  2. ระบบเตือน

    ล่วงหน้า 14 วัน หรือเหลือไม่เกิน 50 ชม.เครื่อง

  3. ใบสั่งซ่อม

    รอดำเนินการ → กำลังซ่อม → เสร็จแล้ว

  4. รายงานค่าซ่อม

    ค่าซ่อมแยกตามเรือ

ชั่วโมงเครื่อง

บันทึกตอนออกเรือ เข้าท่า และตอนซ่อม หรือบันทึกเองที่แท็บ ชั่วโมงเครื่อง ใช้คำนวณรอบซ่อมและน้ำมันต่อชั่วโมง

หมวดงานซ่อม

เครื่องยนต์ตัวเรือไฟฟ้าไฮดรอลิก/กว้านความปลอดภัยเครื่องมือประมงห้องเย็นขึ้นคาน
11

พนักงานและเอกสาร

เมนู พนักงาน/ลูกเรือ และ เอกสารใกล้หมดอายุ · ทะเบียนลูกเรือ คนไทยและแรงงานต่างด้าว พร้อมเอกสารประจำตัว

ข้อมูลพนักงาน

  • ตำแหน่ง เรือที่ประจำ สัญชาติ ช่องทางติดต่อ
  • บัญชีธนาคารสำหรับจ่ายค่าแรง
  • เอกสารแต่ละฉบับ พร้อมวันหมดอายุ

ข้อมูลส่วนบุคคล (PDPA)

เลขบัตร เลขบัญชี เลขเอกสาร เข้ารหัสในฐานข้อมูล และแสดงแบบปิดบังบางส่วนสำหรับผู้ที่ไม่มีสิทธิ์

เอกสารที่ระบบติดตาม (ตั้งค่าเพิ่มได้)

หนังสือเดินทางเอกสารรับรองบุคคล (CI)วีซ่าใบอนุญาตทำงานบัตรชมพูหนังสือคนประจำเรือใบรับรองแพทย์ประกันสุขภาพสัญญาจ้างบัตรประชาชน

  1. 90 วัน

    เตือนครั้งแรก

  2. 60 วัน

    เตือนอีกครั้ง

  3. 30 วัน

    เริ่มต่ออายุ

  4. 7 วัน

    เร่งด่วน

จำนวนวันที่เตือนตั้งได้ที่ ตั้งค่าระบบ · เป็นการเตือนเพื่อการบริหาร ไม่ใช่คำแนะนำทางกฎหมาย

12

เงินเดือนลูกเรือ

เมนู เงินเดือน/ค่าตอบแทน · ตั้งกฎครั้งเดียว ระบบคำนวณจากเที่ยวเรือ วันทำงาน และยอดขายให้ทุกงวด

เงินเดือนค่าจ้างรายวันค่าจ้างรายเที่ยวส่วนแบ่งรายได้ (%)ตามปริมาณสัตว์น้ำโบนัส

  1. กฎค่าตอบแทน

    ตามตำแหน่ง เช่น ลูกเรือ 400 บาท/วัน

  2. สร้างงวด

    ช่วงวันที่ และเรือ

  3. คำนวณ

    ตรวจรายคน มีคำเตือนถ้าหักเกินเกณฑ์

  4. อนุมัติ

    คนละคนกับคนคำนวณ หักเงินเบิกตอนนี้

  5. จ่าย

    สลิปรายคน ไฟล์โอนธนาคาร

เงินเบิก/เงินกู้

เบิกล่วงหน้า หักคืนในงวดเงินเดือน · เงินกู้ ผ่อนหักทีละงวด ยอดค้างอยู่ที่แท็บ เงินเบิก/เงินกู้

สถานะงวด

ร่าง→คำนวณแล้ว→อนุมัติแล้ว→จ่ายแล้ว

อัตราค่าจ้างและเพดานการหัก ควรให้ผู้เชี่ยวชาญกฎหมายแรงงานประมงตรวจก่อนใช้จ่ายจริง

13

บัญชีและรายงาน

เมนู บัญชี · เอกสารจากทุกเมนูลงบัญชีคู่ให้เอง นักบัญชีตรวจ ปิดงวด และออกงบ

เอกสารที่ลงบัญชีอัตโนมัติ

ใบแจ้งหนี้ขายรับชำระใบลดหนี้รับสินค้าเคลื่อนไหวคลังถังน้ำมันน้ำมัน/เสบียงเข้าเที่ยวค่าใช้จ่ายเที่ยวเรือใบสั่งซ่อมงวดเงินเดือนเงินเบิก/เงินกู้ใบแจ้งหนี้ผู้ขายจ่ายชำระผู้ขายค่าเสื่อมราคา

ดูรายการที่ยังไม่ลงได้ที่แท็บ ลงบัญชีอัตโนมัติ

รายงาน (แท็บ รายงาน)

  • งบทดลอง
  • งบกำไรขาดทุน แยกรายเรือได้
  • งบแสดงฐานะการเงิน
  • บัญชีแยกประเภท
  • งบกระแสเงินสด
  • แท็บ ภาษี: ภาษีขาย/ซื้อ ภ.ง.ด.1 ภ.ง.ด.3 ภ.ง.ด.53

  1. เอกสารยืนยัน

    ขาย ซื้อ จ่าย เงินเดือน

  2. สมุดรายวัน

    ผ่านรายการแล้วแก้ไม่ได้ แก้ด้วยการกลับรายการ

  3. กระทบยอดธนาคาร

    จับคู่รายการกับ statement

  4. ปิดงวดบัญชี

    งวดที่ปิดแล้วบันทึกย้อนไม่ได้

  5. ปิดบัญชีสิ้นปี

    โอนกำไรสะสม เริ่มปีใหม่

ผังบัญชี กฎการลงบัญชี และอัตราภาษี ควรให้ผู้สอบบัญชีของบริษัทตรวจก่อนใช้งานจริง

14

ผู้ดูแลระบบ

เมนูกลุ่ม ระบบ · ผู้ใช้งาน บทบาทและสิทธิ์ ประวัติการใช้งาน ตั้งค่าระบบ อีเมลขาออก

ผู้ใช้งาน

สร้างผู้ใช้ กำหนดบทบาทและเรือที่ดูแล รีเซ็ตรหัสผ่านหรือ 2FA ให้ผู้ที่ลืม

ประวัติการใช้งาน

ดูว่าใครสร้าง แก้ไข อนุมัติอะไร เมื่อไร ค่าก่อนและหลังแก้

ตั้งค่าระบบ

ชื่อบริษัท วันเตือนเอกสาร เวลาขาดสัญญาณ GPS รอบเตือนซ่อม บทบาทที่ต้องใช้ 2FA ประเภทเอกสาร

อีเมลขาออก

ยังไม่ได้ตั้ง SMTP ระบบเก็บอีเมลไว้ในหน้านี้แทนการส่งจริง

จากทดลองใช้ สู่ใช้งานจริง

  1. ทดลองกับข้อมูลตัวอย่าง

    ลองทุกเมนูได้เต็มที่

  2. สำรองข้อมูล

    .\fisher.cmd backup

  3. ล้างข้อมูลทั้งหมด

    ตั้งค่าระบบ → พิมพ์ “ลบข้อมูลทั้งหมด” + รหัสผ่าน

  4. ใส่ข้อมูลจริง

    ผู้ใช้ เรือ ลูกเรือ สินค้า ยอดยกมา

  5. เริ่มใช้งานจริง

    หลังกด ล้างข้อมูลไม่ได้อีก

เก็บไฟล์ fisher.env ไว้ที่ปลอดภัยแยกจากไฟล์สำรอง ไฟล์นี้มีกุญแจเข้ารหัสข้อมูล ถ้าหาย จะอ่านข้อมูลส่วนบุคคลเดิมไม่ได้

งานประจำวัน–เดือน

รายการตรวจสำหรับแต่ละฝ่าย ติดไว้ข้างโต๊ะได้

ฝ่ายทุกวันทุกสัปดาห์ทุกเดือน
ไต้ก๋งบันทึกสัตว์น้ำ เหตุการณ์ ค่าใช้จ่ายตรวจรายการรอซิงก์ในมือถือ–
ปฏิบัติการ/กองเรือดูแผนที่สด อ่านการแจ้งเตือนส่งสรุปเที่ยวที่เข้าท่า ตรวจแผนซ่อมบำรุงดูน้ำมันต่อชั่วโมงเครื่อง ต้นทุนต่อ กก.
ขายออกใบขาย รับชำระตามลูกหนี้ค้างชำระรายงานยอดขาย
จัดซื้อ/คลังรับสินค้า เบิกเสบียงเข้าเที่ยวอนุมัติใบขอซื้อตรวจนับและปรับยอดสต็อก
บุคคล–เปิดหน้าเอกสารใกล้หมดอายุอัปเดตลูกเรือเข้า-ออก
บัญชีตรวจรายการลงบัญชีอัตโนมัติตั้งหนี้และจ่ายผู้ขายเงินเดือน กระทบยอดธนาคาร ค่าเสื่อม ปิดงวด
ผู้ดูแลระบบสำรองข้อมูลดูประวัติการใช้งานที่ผิดปกติลองกู้คืนไฟล์สำรอง 1 ครั้ง
16

คำถามพบบ่อย

ปัญหาที่เจอบ่อยและวิธีแก้

ลืมรหัสผ่าน

ให้ผู้ดูแลระบบกด รีเซ็ตรหัสผ่าน ที่เมนูผู้ใช้งาน ถ้าเป็น admin คนเดียว ใช้ .\fisher.cmd reset-password บนเครื่องที่ติดตั้ง

หาเมนูไม่เจอ

บทบาทของคุณไม่มีสิทธิ์เมนูนั้น ติดต่อผู้ดูแลระบบให้เพิ่มสิทธิ์

แก้หรือลบเอกสารที่ยืนยันแล้วไม่ได้

ตั้งใจให้เป็นแบบนั้น เพื่อให้บัญชีตรวจสอบได้ ใช้ ยกเลิก ใบลดหนี้ หรือกลับรายการ แทนการลบ

ทำไมมีป้าย “จำลอง”

เป็นข้อมูลตัวอย่างหรือสัญญาณ GPS จำลอง ใช้ทดลองระบบ ล้างทิ้งได้ก่อนเริ่มใช้งานจริง

แผนที่ไม่ขึ้นภาพ

ภาพแผนที่โหลดจาก OpenStreetMap ต้องต่ออินเทอร์เน็ต ถ้าขึ้น Access blocked ให้อัปเดตระบบเป็นรุ่นล่าสุด

มือถือส่งตำแหน่งไม่ได้

เบราว์เซอร์อนุญาตให้ใช้ GPS ของมือถือเฉพาะเว็บที่เป็น https:// ต้องตั้ง HTTPS ให้ระบบก่อน

ข้อมูลส่วนบุคคลแสดงเต็มเฉพาะผู้ที่มีสิทธิ์ ตามหลัก PDPA
